## Pendientes exactos que requieren tu entorno o tu cuenta

1. Abrir Docker Desktop → `npm run obs:alloy:fmt`, `npm run test:infrastructure`, `npm run test:e2e`.
2. Crear `observability/.env.grafana-cloud` (endpoint OTLP, Instance ID, token con
   `metrics:write`/`logs:write`/`traces:write`) → `npm run obs:up`.
3. `npm run k6:smoke` (local) y registrar resultados en [06](06-pruebas-rendimiento.md).
4. En Grafana Cloud: verificar nombres de métricas, importar los 3 dashboards, configurar
   derived field `trace_id`, importar/crear las alertas.
5. Token de Grafana Cloud k6 → `npm run k6:smoke:cloud`.
6. `npm run obs:fault-drill -- redis --with-telemetry` como alerta controlada.
